# Cross-Domain Aspect-Based Review Analysis with a Fine-Tuned Open-Source LLM

Capstone (CS5998), R.M.D.S. Rathnayake, 268486N.

Extracts (aspect, sentiment) pairs from product reviews with a spaCy baseline, a prompted LLM and a QLoRA fine-tuned LLM. The models are trained on SemEval-2014 laptop and restaurant reviews and evaluated on Amazon clothing reviews to measure the cross-domain drop.

The project is in [`capstone-absa-colab-v4/`](capstone-absa-colab-v4/). Its [README](capstone-absa-colab-v4/README.md) has the status, data, results and steps to reproduce.
